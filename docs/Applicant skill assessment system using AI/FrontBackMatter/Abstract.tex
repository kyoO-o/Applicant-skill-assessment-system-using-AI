\textit{\textbf{Түлхүүр үгс: \keywordnames}}
\bigskip

Энэхүү дипломын ажилд ажил горилогчийн ур чадварыг ажлын байрны шаардлагад тулгуурлан хиймэл оюунаар үнэлэх веб суурьтай систем боловсруулсан. Систем нь ажил олгогч болон ажил горилогч гэсэн хоёр үндсэн хэрэглэгчид зориулагдсан бөгөөд ажил горилогч PDF хэлбэрийн CV өөрийн дансаас байршуулснаар Anthropic компанийн Claude Haiku томоохон хэлний загвар (LLM) ажлын байрны шаардлагатай харьцуулан тайлбарлах боломжтой (explainable) үнэлгээ хийж өгнө. Үнэлгээний үр дүнд нийцлийн хувь, тохирсон ур чадварууд, дутуу ур чадварууд болон зөвлөмжүүд агуулагдана.

Чатботын модуль нь RAG (Retrieval-Augmented Generation) аргачлалыг ашиглан PostgreSQL өгөгдлийн сангаас идэвхтэй ажлын байрны мэдээллийг динамикаар олж авч, Claude API-д контекст болгон дамжуулдаг тул хэрэглэгчийн асуултад тухайн үеийн бодит мэдээлэлд суурилсан хариулт өгнө. Мөн ажил олгогч тал нь ирсэн CV-үүдийг AI-ийн үнэлгээний дүнгээр нь харж, сонгон шалгаруулах болон ажил горилогчид даалгавар илгээх боломжтой. Системийг Go (Golang) хэлэн дээр Chi router болон GORM ашиглан, Nuxt 4 болон shadcn/vue UI сангаар хэрэглэгчийн интерфэйсийг хөгжүүлсэн бөгөөд PostgreSQL өгөгдлийн санг ашигласан.
