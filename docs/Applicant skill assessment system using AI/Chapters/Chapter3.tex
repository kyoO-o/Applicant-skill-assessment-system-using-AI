\section{Системийн архитектур}

\par{}\indent Энэ систем нь ажил горилогч, ажил олгогч болон хиймэл оюунд суурилсан үнэлгээний бүрэлдэхүүн хэсгүүдээс бүрдэх тул архитектурыг \textbf{модульчилсан монолит (Modular Monolithic Architecture)} байдлаар зохион байгуулна. Энэ архитектур нь нэг кодын хувьд нэг боловч логикийн хувьд тусдаа модульд хуваагдсан бүтэцтэй тул хөгжүүлэлт, тест, deployment хийхэд харьцангуй энгийн бөгөөд системийн дотоод зохион байгуулалт ойлгомжтой байдаг.

\begin{figure}[H]
    \centering
    \includegraphics[scale=0.38]{Figures/chapter3/modular_monolith.png}
    \caption{Системийн архитектур}
    \label{fig:sys_arch}
\end{figure}

\par \noindent Системийн back-end хэсгийн кодын бүтэц нь домэйн чиглэлтэй модульчлалын зарчмыг баримтлан, REST архитектурын загварт \cite{fielding2000rest} нийцүүлэн дараах байдлаар зохион байгуулагдсан:

\begin{itemize}
    \item \textbf{aiman} --- Anthropic Claude API-тай харилцах AI клиент модуль. CV үнэлгээ (\texttt{AssessCV}), чатбот (\texttt{Chat}), даалгавар автоматаар үүсгэх (\texttt{GenerateTask}) болон CV мэдээлэл задлах (\texttt{ParseCV}) үйлдлүүдийг хэрэгжүүлнэ.
    \item \textbf{jobman} --- Ажлын байрны удирдлагын модуль. \texttt{JobPosting} болон холбоотой \texttt{Duty}, \texttt{Requirement}, \texttt{Skill}, \texttt{Bonus} загварчлалуудыг удирддаг.
    \item \textbf{appman} --- Ажил горилогчийн анкетийн удирдлагын модуль. Анкетийн мэдээлэл болон AI үнэлгээний үр дүнг хадгалж удирддаг.
    \item \textbf{taskman} --- Даалгаврын удирдлагын модуль. Ажил олгогчоос үүсгэсэн даалгавар болон ажил горилогчийн гүйцэтгэлийн илгээлтийг хянадаг.
    \item \textbf{cvman} --- CV профайлын удирдлагын модуль. Ажил горилогчийн дэлгэрэнгүй CV мэдээллийг JSON хэлбэрт хадгалж удирддаг.
    \item \textbf{userman} --- Хэрэглэгчийн удирдлагын модуль. Нэвтрэлт, бүртгэл, session удирдлага болон эрхийн хяналтыг хэрэгжүүлнэ.
\end{itemize}

\par \noindent Front-end хэсэг нь Nuxt 4-ийн файл суурилсан маршрутлалыг ашигласан бөгөөд үндсэн хуудаснуудад: ажлын байрны жагсаалт (\texttt{/jobs}), ажлын байрны дэлгэрэнгүй болон анкет илгээх хуудас (\texttt{/jobs/[id]}), ажил горилогчийн анкетийн хуудас (\texttt{/applications}), чатботын хуудас (\texttt{/chat}), CV профайлын хуудас (\texttt{/cv}), даалгаврын хуудас (\texttt{/tasks}), ярилцлагын хуудас (\texttt{/interviews}) зэрэг орно. API дуудлага болон өгөгдлийн загварчлалыг \texttt{composables/api/} болон \texttt{composables/types/} хавтасд тусдаа удирдана.

\section{AI модулийн хэрэгжилт}

\paragraph{} Системийн хиймэл оюуны функцуудыг \texttt{aiman} дотор хэрэгжүүлсэн бөгөөд Anthropic Claude Sonnet (\texttt{claude-sonnet-4-6}) загвартай \cite{anthropic2024claude} шууд HTTP дамжуулалтаар харьцдаг. Тус package нь дөрвөн үндсэн функцийг агуулна: CV үнэлгээний \texttt{AssessCV}, чатботын \texttt{Chat}, даалгавар үүсгэх \texttt{GenerateTask} болон CV мэдээлэл задлах \texttt{ParseCV}.

\subsection*{CV-ийн үнэлгээ (AssessCV)}

\par \noindent \texttt{AssessCV} функц нь ажил горилогчийн CV текстийг болон ажлын байрны гарчиг, шаардлага, ур чадвар, үүрэг хариуцлагыг авч, Claude API-д дамжуулан бүтэцлэгдсэн JSON үнэлгээ буцаадаг. Систем нь \texttt{system} role-д AI-д HR шинжээчийн үүрэг тодорхойлон өгч, \texttt{user} role-д ажлын байрны бүх мэдээлэл болон CV текстийг нэгтгэн prompt болгон дамжуулдаг. Claude API-ийн хариулт дараах талбаруудыг агуулсан JSON форматтай байдаг:

\begin{itemize}
    \item \textbf{overall\_score} --- 0--100 хооронд нийт нийцлийн оноо
    \item \textbf{summary} --- Монгол хэл дээр 2--3 өгүүлбэрийн ерөнхий дүгнэлт
    \item \textbf{matched\_skills} --- Тохирсон ур чадвар бүрд яагаад тохирохыг тайлбарласан жагсаалт
    \item \textbf{missing\_skills} --- Дутуу ур чадвар бүрд яагаад дутуу байгааг тайлбарласан жагсаалт
    \item \textbf{duty\_assessments} --- Үүрэг хариуцлага бүрийн биелэлт (\texttt{met}/\texttt{partial}/\texttt{not \_met}) болон тайлбар
    \item \textbf{requirement\_assessments} --- Шаардлага бүрийн биелэлт (\texttt{met}/\texttt{partial}/\texttt{not \_met}) болон тайлбар
    \item \textbf{recommendations} --- Ажил горилогчид зориулсан сайжруулах зөвлөмжүүдийн жагсаалт
\end{itemize}

\par \noindent Ажил горилогч CV файлаа илгээхэд систем дараах дарааллаар ажиллана:
\begin{enumerate}
    \item \texttt{pdfcpu} сангийн тусламжтайгаар PDF файлаас текст задлана.
    \item Задлагдсан текстийг ажлын байрны мэдээлэлтэй хамт prompt болгон бүрдүүлнэ.
    \item Claude API-д HTTP POST хүсэлт явуулна.
    \item API хариулт JSON-г задлаж, \texttt{applications} хүснэгтэд хадгалдаг.
    \item WebSocket дамжуулан ажил горилогчид үнэлгээ дууссан тухай бодит цагийн мэдэгдэл илгээнэ.
\end{enumerate}

% \subsection*{Чатботын хэрэгжилт (Chat)}

% \par \noindent Чатботын хувьд өгөгдлийн санд суурилсан контекст оруулах аргыг хэрэгжүүлсэн. \texttt{Chat} функц нь хэрэглэгчийн мессежийг хүлээн авах бүрт PostgreSQL өгөгдлийн сангаас бүх идэвхтэй (\texttt{posted} статустай) ажлын байруудын гарчиг, байршил, цалингийн хүрээ, ур чадваруудыг татаж, тэдгээрийг нэг мөрийн форматаар Claude API-д дамжуулах prompt-д контекст болгон нэмдэг. Claude нь тухайн контекст болон хэрэглэгчийн асуулт дээр тулгуурлан хариулт үүсгэнэ. Мөн харилцааны өмнөх түүхийг (\texttt{history}) параметрээр дамжуулдаг тул чатбот олон ээлжийн тасралтгүй харилцааг дэмждэг.

\subsection*{Даалгавар автоматаар үүсгэх (GenerateTask)}

\par \noindent \texttt{GenerateTask} функц нь сонгогдсон ажлын байрны шаардлага болон ур чадваруудыг авч, тэдгээрт тохирсон практик даалгавар автоматаар үүсгэдэг. Claude API нь даалгаврын гарчиг болон дэлгэрэнгүй тайлбарыг JSON форматаар буцаана. Ажил олгогч AI-р үүсгэгдсэн даалгаврыг харах, засах болон батлах боломжтой. Систем нь автоматаар үүсгэгдсэн даалгаврыг \texttt{created\_by\_ai = true} тэмдэглэгээтэй хадгалдаг бөгөөд энэ нь статистик, тайлагнал хийх үед ашиглагдана.

\subsection*{CV-ийн мэдээлэл задлах (ParseCV)}

\par \noindent \texttt{ParseCV} функц нь чөлөөт форматтай CV текстээс бүтэцлэгдсэн мэдээллийг автоматаар задалдаг. Монгол болон Англи хэлний CV-г аль алинийг нь ойлгох чадвартай. Задлагдсан хариулт нь хэрэглэгчийн нэр, холбоо барих мэдээлэл, ажлын туршлага, боловсрол, ур чадвар, гадаад хэл зэрэг олон талбарыг агуулсан JSON хэлбэртэй байдаг. Ингэснээр ажил горилогч CV файлаа оруулахад \texttt{/cv} хуудас дахь профайл автоматаар бөглөгдөнө.

\section{Хөгжүүлсэн системийн интерфейс}

\section*{Бүлгийн дүгнэлт}

\paragraph{} Энэ бүлэгт ажил горилогчийн ур чадварыг үнэлэх системийн зохиомж болон хөгжүүлэлтийг дэлгэрэнгүй тайлбарласан.

Системийн архитектурыг модульчилсан монолит загварын дагуу front-end (Nuxt 4 + Vue 3), back-end (Go + Chi router), өгөгдлийн сан (PostgreSQL) болон гадаад үйлчилгээ (Claude API, Google Calendar API) гэсэн давхаргуудад хувааж зохион байгуулсан. Back-end кодын бүтцийг \texttt{aiman}, \texttt{jobman}, \texttt{appman}, \texttt{taskman}, \texttt{cvman}, \texttt{userman} зэрэг домэйнчилсан тусдаа модулиудад хуваасан. Зохиомжийн шатны класс диаграммд \texttt{Company}, \texttt{User}, \texttt{JobPosting}, \texttt{Application}, \texttt{Task}, \texttt{TaskSubmission}, \texttt{CVProfile} зэрэг бүх үндсэн классуудыг болон тэдгээрийн нэг-нэгт, нэг-олон харьцааг тодорхойлсон.

AI модулийн хүрээнд Anthropic Claude Sonnet загвар ашиглан CV үнэлгээний \texttt{AssessCV}, даалгавар автоматаар үүсгэх \texttt{GenerateTask} болон CV мэдээлэл задлах \texttt{ParseCV} функцуудыг хэрэгжүүлсэн. \texttt{AssessCV} нь нийт оноо, тайлбарласан тохирсон болон дутуу ур чадварууд, шаардлага болон үүрэг хариуцлага бүрийн биелэлт, сайжруулах зөвлөмжүүдийг агуулсан бүтэцтэй JSON хариулт буцаадаг. Ярилцлагын цаг товлохдоо Google Calendar API-тай интеграц хийж, ажил горилогчийн имейл хаягт мэдэгдэл автоматаар илгээгддэг болсон. Хөгжүүлсэн системийн ажлын байрны жагсаалт, анкет илгээх болон AI үнэлгээ харах, ажил олгогчийн удирдлагын самбар, даалгаврын удирдлага болон ирсэн анкетуудын жагсаалт зэрэг үндсэн интерфейсүүдийг харуулсан.
